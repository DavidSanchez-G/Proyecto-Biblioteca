## 📖 Descripción

Proyecto enfocado en la digitalización y gestión documental de una biblioteca, permitiendo organizar, catalogar y consultar recursos digitales de forma eficiente. La aplicación busca mejorar la accesibilidad y preservación de documentos mediante una plataforma intuitiva y escalable.

Este sistema facilita la administración de contenido bibliográfico y optimiza el acceso a la información digitalizada.

---

## 🚀 Características

- Gestión de documentos digitales
- Sistema de búsqueda y consulta
- Catalogación de recursos bibliográficos
- Gestión de usuarios
- Instalación completa
- Arquitectura preparada para escalabilidad

---

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- Apache
- Ubuntu Server

---

## 🎯 Objetivos del proyecto

- Mejorar la organización documental.
- Facilitar el acceso a recursos digitalizados.
- Optimizar la gestión bibliográfica.
- Aplicar buenas prácticas de desarrollo web.
